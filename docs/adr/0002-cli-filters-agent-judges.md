# The Rust CLI filters; a headless agent judges

Each run is split in two. The Rust CLI does everything deterministic: it fetches the structured sources (ICS calendars, the hackathonhub sitemap, the Devpost JSON), removes duplicates, applies the hard Profile rules it can check from data alone (dates, Countries, Train limit), stores results and sends Alerts. It then hands the surviving candidates to the person's own AI agent, run headless (`claude -p` by default, behind an interface so others such as Codex can be added), which reads each event page and decides what needs judgement: whether it is really a Hackathon, Eligibility, whether it is Travel-funded, and the return fare. We chose this over one agent doing everything (how the personal version works) because it cuts the tokens each run costs the person, and makes the rules testable and repeatable.
